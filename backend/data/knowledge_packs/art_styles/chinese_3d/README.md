# 国漫 3D 画风知识包

## 画风定位

国漫 3D（Chinese 3D）以「三渲二」美学为主流：三维建模 + 二维卡通渲染（NPR），
线条干净、色彩明快、表情夸张。代表风格：《斗罗大陆》《凡人修仙传》动画版。

## 核心规范

### 角色美术
- 比例：Q版/半身（2头身-5头身），头部偏大，五官简化为大眼+小鼻小嘴
- 发型：发丝成束（块状发），单色底+亮面发丝挑染，拒绝写实发丝
- 服饰：剪裁简化，纹样用贴图而非三维雕刻（欧式纹/中式云纹/图腾）
- 表情：夸张度 +50%（怒瞪、泪眼、邪笑），配合口型开合 2-3 档

### 场景/道具
- 场景：剪影优先（前景主体 + 背景虚化渐变），材质简化为主色+强调色
- 特效：粒子化（光效、气劲用点/线光效而非真实体积光）
- 镜头：强调「推拉摇移」与「大特写」，战斗使用动态模糊 + 震屏

### 配色
- 主色纯度 +20%，阴影色相偏移（冷暖补色），高光用亮色勾边
- 天空/环境色偏童话（星空紫、晨光金、魔幻绿），拒绝写实灰调

## 巡检关注点
- 发型发色跨章节一致性（帧间必须锁定角色卡）
- 服饰纹样/配色是否与角色卡设定冲突
- 场景风格是否混入写实质感（建模偏真实材质即判漂移）
