# 现实都市画风知识包

## 画风定位

现实都市（Realistic Urban）以真实感为主线：偏写实的人物比例、真实光影、
城市街景细节。代表风格：《上海堡垒》《镇魂街》真人化审美方向的动画/漫剧。

## 核心规范

### 角色美术
- 比例：标准 7 头身（写实），五官立体（鼻梁/颧骨/下颌有结构）
- 发型：真实发丝层次（刘海/鬓角/发尾），允许挑染但整体自然
- 服饰：都市穿搭（西装/风衣/卫衣），版型合身，面料质感可见（呢料/皮革/棉）
- 表情：收敛克制（+10%），微表情为主（眼神变化、嘴角微动）

### 场景/道具
- 场景：真实透视 + 环境光（黄昏暖光/雾霾冷光/霓虹夜景），玻璃反光、地面湿润感
- 特效：克制（火花/烟雾写实），拒绝粒子光效滥用
- 镜头：稳（固定机位 + 慢摇为主），只在高潮用快速剪辑

### 配色
- 低饱和主色 + 高对比环境（办公蓝灰、夜霓红、警局冷白）
- 光影强调「时间感」：晨/午/暮/夜的色温差必须可感知

## 巡检关注点
- 角色服装/发型跨章节一致性（正装↔休闲切换需剧情依据）
- 场景时间感是否与剧情时间一致（白天黑夜的色温逻辑）
- 道具细节（手机型号年份、街景标识）是否穿越年代
