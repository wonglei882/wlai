# 都市职场题材知识包

## 题材特征

都市职场（Urban/Workplace）锚定现实世界职业场景，以职场博弈、商战权谋、情感纠葛为核心驱动。
读者期待的是「专业感」与「逆袭爽感」的结合——主角凭真本事（而非金手指）赢得尊重。

## 核心原则

1. **职业真实感**：行业细节、职位头衔、业务流程必须符合现实逻辑（金融/法律/互联网各有专业门槛）。
2. **实力有据**：主角的行业能力需要背景支撑（履历/项目经验/学习成长），不能凭空开挂。
3. **职场有度**：权力斗争要符合组织架构现实（越级汇报要承担后果、利益交换要等价）。
4. **矛盾有根**：反派针对主角需有动机链条（利益冲突/旧怨/派系斗争），不能无理由作恶。
5. **节奏有呼吸**：商战/博弈段落之间要有生活日常和人物关系戏调剂。

## 写作节奏（都市版）

- 小冲突（会议交锋/方案被抢）：每 2-3 章一个
- 中冲突（项目危机/岗位竞聘）：每 8-12 章一个
- 大冲突（并购战/公司危机/职场整肃）：每 25-40 章一个
- 项目/事件本身要有「立项→执行→危机→解决」的完整弧线

## 常见易错点（巡检重点关注）

1. 行业常识错误（如金融术语、法律流程、财报逻辑不真实）
2. 主角能力无来源（空降神技，无前文铺垫）
3. 职级权力错乱（实习生指挥 VP、老板轻易被要挟）
4. 商战手段低幼（现实中可笑的阴谋被写成高智商博弈）
5. 时间线混乱（项目 deadline 与章节目期对不上）
