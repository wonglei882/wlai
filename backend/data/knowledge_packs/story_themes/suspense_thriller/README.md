# 悬疑惊悚题材知识包

## 题材特征

悬疑惊悚（Suspense/Thriller）以谜题构建、信息落差、心理博弈为核心驱动。
读者期待的是「本以为猜到、却被反转」的智力快感与「细思极恐」的余韵。

## 核心原则

1. **线索诚实**：所有关键线索必须在揭晓前给出（可误导但不可凭空），读者回看必须能发现伏笔。
2. **伏笔纪律**：每个埋下的伏笔都要有回收计划，悬疑题材最忌「挖坑不填」。
3. **真相有价**：每个真相的揭晓必须付出代价（牺牲/背叛/崩塌），不能零成本获得。
4. **加害有锚**：凶手/幕后黑手的动机必须在人性逻辑内成立（利益/恐惧/执念），不能为反转而反转。
5. **信息差**：主角与读者的信息差是悬疑的核心引擎，必须精细管理「谁知道什么、何时知道」。

## 写作节奏（悬疑版）

- 小疑点（细节异常/人物表现反常）：每 1-2 章埋一个
- 中反转（嫌疑人替换/线索重新解读）：每 5-8 章一个
- 大反转（真凶揭露/核心谜题破解）：每 15-25 章一个
- 收束期：最后 5 章内所有伏笔回收，禁止最后 1 章空降新真相

## 常见易错点（巡检重点关注）

1. 关键线索从未铺垫（空降证据反转）
2. 伏笔超期未回收（超过 30 章即触红线 RL-003）
3. 信息差管理混乱（角色突然知道不该知道的事）
4. 凶手动机牵强（纯为反转设计）
5. 技术细节硬伤（法医/监控/刑侦流程违背现实）
