# 仙侠奇幻叙事手法

## 规划与铺垫（Setup）

### 修炼爬升节奏规划
- 境界爬升采用「阶梯式」而非「直线式」：每个大境界内部划分 3 个小阶段（初期/中期/圆满）
- 主角每跨越一个小阶段，至少铺垫 2 个前置事件（资源获取 + 瓶颈对抗）
- **伏笔安排**：跨越境界需要的「机缘」应在 5 章前埋下（如秘境开启预告、古老传承线索）

### 境界突破三幕结构
1. **机缘幕**：获得突破契机（天材地宝 / 传承 / 生死顿悟）
2. **淬炼幕**：突破过程的磨难（心魔劫 / 雷劫 / 外力干扰）
3. **升华幕**：突破成功 + 能力展示 + 留下后遗症钩子（如境界不稳伏笔）

## 高潮与战斗（Climax）

### 越级挑战规则
- 允许越 1 个大境界挑战（主角光环），需付出：重伤 / 修为跌落 / 法宝损毁
- 越 2 个大境界必须借助外物（阵法/合击/天地之势）且赢得侥幸
- 禁止无代价秒杀高阶（读者会失去紧张感）

### 战斗描写节奏
- 战斗前：交代双方实力对比 + 地形/天时/人势
- 战斗中：至少 1 次「危机转折」（优势转劣势再翻盘）
- 战斗后：战利品盘点 + 战损复盘 + 对后续剧情的推动

## 世界观与法则（Worldbuilding）

### 天道法则一致性
- 灵气浓度起伏必须有原因（灵脉变动 / 大能陨落 / 天地异变）
- 飞升通道的开闭、雷劫强度变化要呼应前文伏笔
- 因果报应成为叙事工具时，需保持「有因必有果」的对等性

### 势力格局
- 门派实力与资源成正比（大门派占大灵脉，冲突焦点也应是大利益）
- 宗门内斗是常用的中段冲突，但不得影响主线境界推进超过 10 章
