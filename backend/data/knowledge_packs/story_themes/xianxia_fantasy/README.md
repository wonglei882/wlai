# 仙侠奇幻题材知识包

## 题材特征

仙侠奇幻（Xianxia/Fantasy）以修炼体系为核心驱动力，融合东方神话、道家哲思与热血成长叙事。
读者期待的是「逆天改命」的爽感与「大道三千」的世界观纵深。

## 核心原则

1. **境界体系是脊柱**：修炼境界（炼气→筑基→金丹→元婴→化神→渡劫→大乘→飞升）必须严格自洽，
   任何越级突破/倒退都必须有铺垫与代价。
2. **实力有度**：主角可以越级挑战，但必须付出代价（重伤/宝物损毁/境界不稳），不能无代价碾压。
3. **天地法则有界**：世界观内天道规则（如灵气浓度、飞升雷劫、因果约束）一旦设定必须贯穿始终。
4. **宝物有源**：法宝/丹药/传承必须交代来源、品级、限制（认主/反噬/使用次数）。
5. **成长有节点**：每个大境界突破需包含：机缘（获得）→ 磨难（淬炼）→ 顿悟（升华）三幕结构。

## 写作节奏（参考 pacing.md 通用节奏的题材化变体）

- 小高潮（同境界内突破/战斗）：每 3-5 章一个
- 中高潮（跨境界突破）：每 10-15 章一个
- 大高潮（门派战/渡劫/飞升）：每 30-50 章一个
- 境界突破后必须给 1-2 章的「消化期」（稳固境界 + 收获盘点 + 新目标埋线）

## 常见易错点（巡检重点关注）

1. 境界倒退无解释（渡劫失败除外，且需描写代价）
2. 同境界实力忽高忽低（打同阶有来有回，打低阶秒杀——需保持一致）
3. 法宝规则前后矛盾（如储物袋容量、飞剑速度）
4. 天地法则被轻易打破（如凡人灭仙、无灵根修仙不被反噬）
5. 修炼时间线错乱（闭关年份与外界事件时间对不上）
